# Package index

## Main Functions

Primary functions for risk assessment and reclassification

- [`ggrap()`](https://researchverse.github.io/raptools/reference/ggrap.md)
  : The Risk Assessment Plot
- [`ggdecision()`](https://researchverse.github.io/raptools/reference/ggdecision.md)
  : The Decision curve
- [`ggcalibrate()`](https://researchverse.github.io/raptools/reference/ggcalibrate.md)
  : The Calibration plot
- [`ggroc()`](https://researchverse.github.io/raptools/reference/ggroc.md)
  : The ROC plot
- [`ggprerec()`](https://researchverse.github.io/raptools/reference/ggprerec.md)
  : The Precision-Recall plot
- [`ggcontribute()`](https://researchverse.github.io/raptools/reference/ggcontribute.md)
  : The Contribution plot
- [`meta.rap()`](https://researchverse.github.io/raptools/reference/meta.rap.md)
  : List meta data
- [`summary(`*`<rap>`*`)`](https://researchverse.github.io/raptools/reference/summary.rap.md)
  : List risk assessment metrics

## Classification Metrics

Functions for calculating reclassification metrics

- [`CI.classNRI()`](https://researchverse.github.io/raptools/reference/CI.classNRI.md)
  : Statistical metrics and confidence intervals for classes
- [`CI.raplot()`](https://researchverse.github.io/raptools/reference/CI.raplot.md)
  : Statistical metrics with confidence intervals
- [`statistics.classNRI()`](https://researchverse.github.io/raptools/reference/statistics.classNRI.md)
  : Reclassification metrics with classes (ordinals) as inputs
- [`statistics.raplot()`](https://researchverse.github.io/raptools/reference/statistics.raplot.md)
  : Statistical metrics
- [`extractCI()`](https://researchverse.github.io/raptools/reference/extractCI.md)
  : Extract confidence interval
- [`extract_NRI_CI()`](https://researchverse.github.io/raptools/reference/extract_NRI_CI.md)
  : Extract NRI confidence intervals

## Data and Utilities

Example datasets and utility functions

- [`data_class`](https://researchverse.github.io/raptools/reference/data_class.md)
  : Simple data set with classifications
- [`data_risk`](https://researchverse.github.io/raptools/reference/data_risk.md)
  : Simple data set with risk predictions
- [`anova_glm()`](https://researchverse.github.io/raptools/reference/anova_glm.md)
  : The function anova_glm() returns the Chi^2 and degrees of freedom
  for each variable & the same was anova.rms() does from lrm() in the
  rms package.
- [`ggcalibrate_original()`](https://researchverse.github.io/raptools/reference/ggcalibrate_original.md)
  : The Original Calibration plot
